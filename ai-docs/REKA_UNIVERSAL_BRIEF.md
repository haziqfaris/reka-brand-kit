## Visual language (Main tier)

- **Chamfer cuts, not border-radius.** Use `clip-path: polygon(...)` for all UI panels.
- **Orange is an accent, not a fill.** Max ~10% of surface area.
- **Dark instrument-panel aesthetic** on internal/brand materials.
- **Warm light surface** (`#F7F6F3`) on public/client-facing materials.

## Hard copy rules (non-negotiable)

1. **No em dashes** — use commas or parentheses instead.
2. **No currency figures** — use multiples (2×) or percentages, flagged as "(illustrative)" if not real.
3. **"Malaysia's first"** self-driving car on open roads (2016). Never "Southeast Asia's first".
4. **"Founder"** not CEO.
5. **No fabricated metrics** or partnerships. Flag illustrative data.
6. **"Autoware Foundation member"** — never "representative".
