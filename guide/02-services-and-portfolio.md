# 02 Services and portfolio

## Four ways of working ("Four doors. One way of working.")

Visitors arrive knowing their problem, not REKA's service names, so reka.re starts from their situation:

| Situation | Way | Service | What it is |
|---|---|---|---|
| "I know AI matters, but not where to start." | 01 **Advise** | Consulting and Advisory | Figure out the right move before you spend: assessments, roadmaps, vendor-neutral strategy. |
| "I know what I need. I need it built right." | 02 **Build** | Custom Build and R&D | Build what doesn't exist yet: software, AI, hardware, robotics, designed for the environment. |
| "I need AI run for me, without a team." | 03 **Managed** | Managed AI | AI run for you: hosted, monitored and improved on one subscription. Runs inside the customer's environment when data can't leave. |
| "I need to automate how my operation runs." | 04 **Automate** | Intelligent Automation | Automate the busywork across an operation, with a human in the loop where it matters. |

The constant: **"Whichever door, we sell return, not software."**

## Method

Two expressions exist and must be reconciled (see 09 Open questions):

- **Playbook (v0.3):** SEE → PROVE → BUILD → ADVANCE. "Bespoke implementation. Proven framework."
- **Live site:** six stages, where technology enters only at stage three: Diagnose ("no tech yet") → Quantify ("no tech yet") → Architect ("tech enters") → Prove → Shape → Run.

## Managed AI

> **AI, run for you.** You don't need an in-house AI team to get the benefits of AI. We host it, monitor it, improve it and keep it reliable: the models, the infrastructure and the ops, all on one predictable subscription. You get the outcome; we handle the platform.

Four steps: **We set it up** (model, infrastructure, integration, monitoring) → **You use it** (outputs in the interface that fits) → **We watch it** (accuracy and drift, around the clock) → **We improve it** (new capability without a new project).

Promises (only these): one subscription; monitored; improves; private (runs inside your environment when data can't leave).

**Closed pilots:** every AntaraX closed pilot (Frame, PLExyz Crowd, Angka, Tinara, Loom, Motion) is run by REKA as a Managed AI engagement.
