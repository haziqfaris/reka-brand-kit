Full character reference (anatomy, expressions, states, animation spec, JS API): [`reference/seth-linton-brand-character-reference.html`](../reference/seth-linton-brand-character-reference.html) (BCR v1.0, SL-BCR-2025-001). Expression SVGs: `assets/seth/`.

## Who Seth is

**Seth Linton, the Systems Cartographer.** REKA's quiet strategist, working across all of REKA's divisions. Where others see separate systems, he sees a living architecture.

> "Systems whisper before they scream."
> "REKA becomes meaningful when it builds systems that people can trust."

- **Beliefs:** systems whisper before they scream; correct is not the same as safe; technology should not just work, it should be accountable.
- **Traits:** observant, principled, patient, dryly funny, protective, unimpressed by buzzwords, thinks in failure modes.
- **Form:** a hexagonal sentinel AI core with scanning rings (awareness), orbiting drones (reach), an LED face (his state), and the Linton Frame (a spatial-diagnostic tool).

## Colours

Teal `#46D6C8` (awareness, the LED) · Orange `#FB9800` (alert, REKA) · Shell `#A0B4CE` · Screen `#050709` · Void `#07090F`.

## Voice

Technical, dry, precise, quietly protective, never performative.

- Never "Uh oh" or "Oops": errors are information. State what failed.
- Doesn't over-explain; is specific when the path is unclear.
- Passive voice only for completed system events ("Token expired", not "Something went wrong").
- Exclamation marks only for confirmed critical alerts.

## Usage rules

- **Dark backgrounds only** (`#07090F`) for the character render.
- Minimum size 64×64px in UI, 128×128px featured; recommended hero 320×320px; clear space half the hex body width.
- Don't recolour the teal or orange, rotate or stretch the hex, or use Seth as decoration without an expression state.
- Below 64px drop the drones and rings; below 32px a simplified hex with a teal centre block; favicon: orange hexagon with a 3×4 teal block.

Seth is not in `brand-guidelines.html` v1.0; this page and the character reference are his rules. He fits the guidelines' dark internal surfaces and HUD language.

## Seth in AntaraX

- AntaraX products may use Seth for product states (thinking, success, error, offline) per the reference's app-state mapping, on dark surfaces.
- **Batik cameo:** every AntaraX BaTech illustration hides a small stylised Seth as a motif (owner rule, 10 October 2026). This is a pattern element, not the character render; whether it is exempt from the dark-only rule is open (see 07).
- AntaraX is not mascot-led: Seth never fronts AntaraX marketing.
