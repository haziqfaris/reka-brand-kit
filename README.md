# REKA brand kit

The single reference for how REKA looks, sounds and is organised. reka.re, REKA proposals, decks, campaigns, the REKA story, Seth Linton and anything written about REKA should follow this kit.

**REKA Inisiatif Sdn Bhd** is an independent commercial R&D company in Kuala Lumpur, Malaysia, founded in 2013. Its product line is **AntaraX**, which has its own kit: [haziqfaris/AntaraX-brand-kit](https://github.com/haziqfaris/AntaraX-brand-kit).

## The one-minute version

- **Line:** Built for Progress.
- **What REKA is:** a technology R&D and innovation partner. Technology is not the outcome; progress is.
- **Four ways of working:** Advise (consulting), Build (custom build and R&D), Managed (Managed AI), Automate (intelligent automation). Kinetik is the autonomy and robotics division.
- **AntaraX** is where REKA's proven, repeatable capability becomes products. REKA links to AntaraX; it does not sell AntaraX products as its own.
- **Look:** dark, professional, minimal cyberpunk. Near-black ground, off-white ink, REKA orange `#FB9800` with a little orange gradient, Poppins and a lot of JetBrains Mono, sharp corners, engineering-drawing details.
- **Character:** Seth Linton, the systems cartographer.

## How to use and change this kit

1. **This kit wins** over any single page or deck. If the owner decides otherwise, update the kit first.
2. **Record decisions** in [08](guide/08-decisions-log.md) with the date; unresolved items in [09](guide/09-open-questions.md).
3. **Copy tokens, don't retype them.**
4. `reference/` is source material; the guide is current.
